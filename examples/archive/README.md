# Archived experiments

Earlier songs, probes and parameter sweeps kept for reference: the grief
engine, amber hour, lofi evolve and dreamy song iterations, the texture kit
and the knob probes. They show how the toolkit grew, but they are not
maintained: several hard-code a macOS debug build of `magda_cli`, use APIs that
have since been replaced by song specs, presets and the balance pass, or read
`../v4tools.py` from this folder.

For a current end-to-end example see `../glitterstatic.py`; for the engine
protocol see `../p3_engine_smoke.py`.
